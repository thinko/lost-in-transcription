Open the extension from the toolbar — the popup is organized into five tabs. Click items on the Dashboard to jump to the matching tab.

Dashboard

Live summary: display mode, backend, language pair, send frequency, glossary status, and session memory (on/off). Each row is a shortcut into the right tab.

Translation

  • Backend — LibreTranslate, Google, DeepL, or OpenAI-compatible.
  • API key & URLs — as required by the backend (LibreTranslate base URL, OpenAI base URL + model, etc.).
  • Languages — source and target, with optional dialect submenus where supported.
  • Send frequency — realtime (~300 ms), end of sentence, stable text (~1.5 s pause), or timed batch (slider).
  • Test connection — verify reachability and (where applicable) list models or languages.

Display

  • Mode — inline vs side panel.
  • Font size — for translated text.
  • History buffer — cap visible lines in the panel or allow unlimited.
  • When closing panel / disabling translation — ask, stop translation, hide panel, etc.
  • Remember session history — persist caption/translation data on device (48 h retention) or keep meetings ephemeral.

Prompt & Glossary

  • System prompt — for OpenAI-compatible backends; template variables and Reset for a dialect-aware default.
  • Glossary — list of pattern → replacement entries; per-entry enable/disable.

Help & About

  • Extension version
  • Keyboard shortcuts and quick start
  • Why this extension exists (vs built-in Teams translation)
  • Links to GitHub (from manifest.json homepage_url) and privacy policy
  • Legal / trademark / GPLv3 footer
  • Optional debug logging toggle for the browser console
