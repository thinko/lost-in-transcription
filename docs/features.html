Core behavior

  • Real-time translation — captions are sent to your chosen backend with configurable timing (per update, end of sentence, stable pause, or timed batch).
  • Display modes — translations below each caption inline, or in a resizable side panel next to the caption area.
  • MutationObserver-driven — follows Teams caption DOM updates as recognition refines text.

Translation backends

  • LibreTranslate — optional API key; great with public or self-hosted instances.
  • Google Cloud Translation — API key; high-volume neural translation.
  • DeepL — API key; strong for many European language pairs.
  • OpenAI-compatible — API key optional for local use; supports Ollama, LM Studio, vLLM, and cloud endpoints. Dialect-aware system prompts with {{SOURCE_LANG}}, {{TARGET_LANG}}, {{GLOSSARY}} placeholders.

Built-in Test connection and (for OpenAI-compatible) model discovery.

Glossary

User-editable find/replace rules fix mangled technical or product terms before and after translation. Ctrl+Click (or Cmd on Mac) on a word in captions or the translation panel opens a quick popover to add or adjust entries.

Sessions & export

  • Session memory — optional on-device persistence in chrome.storage.local so transcripts can survive refresh and reconnect (up to 48 hours after last update; can be turned off in Display → Behavior).
  • Save & start new — snapshot the current meeting transcript and begin a fresh session.
  • Export — TXT, CSV, or SRT via toolbar or Alt+Shift+E.
  • Re-apply glossary — update saved sessions after glossary changes.

Internationalization

UI ships in English, French, Spanish, German, and Japanese. Language dropdowns can show native names alongside English (e.g. “Français (French)”).

Teams hosts

The extension is enabled on Microsoft-documented origins, including commercial Teams, teams.cloud.microsoft, government clouds, China tenants, and related Skype/Lync patterns. See the README for the full list.
