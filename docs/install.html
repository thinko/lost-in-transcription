From source (Chrome or Edge)

  1. Clone or download the repository: github.com/thinko/lost-in-transcription
  2. Open chrome://extensions (Chrome) or edge://extensions (Edge).
  3. Enable Developer mode.
  4. Click Load unpacked and select the repository folder (the directory that contains manifest.json).
  5. Pin the extension if you want quick access to settings.
